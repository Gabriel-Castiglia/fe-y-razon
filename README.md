# Fé y Razón

**Apologética católica para entender, vivir y defender la fe.**

🌐 **Sitio web:** [gabriel-castiglia.github.io/fe-y-razon](https://gabriel-castiglia.github.io/fe-y-razon/)

---

## Sobre el proyecto

*Fé y Razón* es un sitio de catequesis apologética que ofrece argumentos sólidos —basados en la Sagrada Escritura, el Magisterio de la Iglesia y la razón natural— para profundizar en la doctrina católica y responder a objeciones modernas, herejías y corrientes anticatólicas.

El proyecto se inspira en las palabras del Señor:

> *"Yo soy el Camino, la Verdad y la Vida."* — Juan 14, 6

## Misión

- **✝️ Enseñar** — Profundizar en la doctrina católica con argumentos sólidos.
- **💡 Iluminar** — Brindar respuestas claras a las preguntas difíciles de la fe.
- **🛡️ Defender** — Ofrecer apologética frente a objeciones, dudas y herejías modernas.

## Temas tratados

- El Sacerdocio
- Por qué creemos

- Los Santos y su intercesión

Sitio estático desplegado mediante **GitHub Pages**. Construido con HTML, CSS y JavaScript puros, sin frameworks.


## Despliegue local

Para visualizar el sitio en tu máquina:

```bash
git clone https://github.com/Gabriel-Castiglia/fe-y-razon.git
cd fe-y-razon
python3 -m http.server 8000
```

Luego abrir [http://localhost:8000](http://localhost:8000) en el navegador.
